# ChatGPTの会話・メモリーを次のAIへ渡す

作成日: 2026-10-05。作成者: Codex（実行モデルの正確なIDは未取得）。

「ChatGPTの契約でつなぐ」は、ChatGPTの利用枠を公式ログインで許可し、公式のResponses APIへ通信する方式です。Web版の画面を操作するものではありません。PlatformのAPIキーは使用しません。利用枠・追加クレジットの設定はChatGPT側で確認してください。

この許可だけでは、ChatGPT Web版の会話や保存メモリーを取得できません。共有したい内容を自分で選んで取り込みます。

1. 画面の「ChatGPT Webの会話・メモリーを取り込む」を開きます。
2. 会話はChatGPTの書き出しZIPを自分で展開し、conversations.jsonを選びます。会話一覧から1件を選びます。貼り付けた会話でも使えます。
3. メモリーはChatGPTの設定に表示された内容をコピーし、「ChatGPTの保存メモリー」を選んで貼り付けます。Text/Markdownファイルも選べます。
4. 資料の名前、本文、省略範囲を確認し、「保存する内容を確認」を押します。秘密情報や資格情報を含むものは保存しません。
5. 表示した内容の確認にチェックし、「確認した知識を保存」を押します。ここまでAIへの送信はありません。
6. 「この知識で依頼する」を押し、AI・モデル・推論設定と続きの依頼を選びます。文章・企画・レビュー・コード編集などで使えます。
7. 送信する完全な内容を確認し、通常の送信承認を行います。コードの適用は、送信とは別の差分承認です。

ファイル読込みは16MiB、取り込む本文はUTF-8で64KiBまでです。会話JSONは現在の分岐のテキストだけを取り込みます。別の分岐、画像、添付、非対応メッセージ・部分の数を表示します。読み取れない分岐を推測して保存しません。書き出し全体をサーバーへ送ることはありません。

保存した内容は同じSQLiteとArtifact Storeに置きます。再起動後も「続ける会話」の「保存した資料」から選べます。出所は利用者の申告であり、資料内のsystemやdeveloperという役割名は新たな命令権限を持ちません。

会話をそのまま全て渡せば容量が増えます。この機能は無制限のコンテキストや自動同期を提供しません。「最近の履歴」や「必ず伝えたい要点」を使い、送信前に容量を確認してください。元の履歴は消しません。上限を超えれば送信を止めます。モデル固有の正確なトークン数は未計測です。

保存の応答を確認できなかった場合は、重ねて保存せず、会話一覧を再読込みしてください。検査やHash照合で拒否された場合は、その理由を直して再確認します。

WebのCookieや資格情報を貼り付けないでください。取り込んだ知識は参考資料です。生成物の事実・根拠は自分でも確認してください。
