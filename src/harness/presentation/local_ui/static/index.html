    受付と復旧
    依頼画面へ ↗
    
  
    途中で止まった処理を確認します。残存状態の整理と受付再開は別々の承認です。生成や送信を再実行する操作ではありません。
    
  
  
    
  
    
  
    参照専用で起動されています。運用操作を使う場合は、端末で現在のOS利用者を確認し、起動コマンドに --operator-auth-session を指定して再起動します。送信・整理・再開の承認は省略されません。手順は USAGE.md の「受付と復旧」を参照してください。
